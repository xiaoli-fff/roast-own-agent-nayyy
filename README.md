A roast of my own AI agent: I asked it for one word, and it sent back a plan, a summary of the plan, and an apology for the summary.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
